# Geomashv2

**GEOMASH** — a neon rhythm platformer built with Vite + Three.js.

## Play

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production bundle in dist/
npm run preview  # serve the production build
```

One-button controls: **click / tap / Space / ↑ / W** to jump and hold to chain jumps. In ship and wave sections, hold to climb and release to dive. Pause with **Esc** or **P**.

## Features

- Three hand-authored levels — **STEREO NEON**, **CYBER DRIFT**, **VOID PROTOCOL** — with cube, ship and wave modes.
- Jump orbs, boost pads, portals, spikes, saws, coins, practice checkpoints and a finish gate.
- Procedural WebAudio synthwave soundtrack and SFX (no external audio assets).
- Neon post-processing, parallax city, particles, shockwaves, trails and camera shake.
- Menu, level select, help, settings, pause, death/retry, completion, save data and adaptive quality.

Progress is stored in `localStorage` under `geomash.save.v2`.
